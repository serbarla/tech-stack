# AGENTS.md — `@acme/expo`

Mobile app: **Expo SDK 58 / React Native 0.88 / React 19**, Expo Router, Uniwind (Tailwind v4), Eden Treaty + TanStack Query. All paths and commands below are relative to `apps/expo/`.

## Commands

```bash
pnpm dev           # expo start
pnpm ios           # expo run:ios   — builds the native dev client from source (ios/ is generated)
pnpm android       # expo run:android
pnpm typecheck     # tsc --noEmit
pnpm lint          # eslint --flag unstable_native_nodejs_ts_config
pnpm format        # prettier --check
pnpm clean         # git clean -xdf .cache .expo android ios node_modules
```

From `sb-stack-v1/`, each script is an Nx target: `pnpm nx run @acme/expo:typecheck`, and root `pnpm dev` runs server + web + expo in parallel.

## Quirks

- **Dev client vs Expo Go**: `expo-dev-client` is installed, so plain `expo start --ios` expects a _dev build_. For Expo Go use `expo start --ios --go`.
- **Never set `CI=` empty** — an empty `CI` breaks the Expo CLI. Use `CI=false`.
- **CNG**: `ios/` and `android/` are generated by prebuild and gitignored (`.gitignore` lines 20–21). Never hand-edit them; native changes go in `app.config.ts` (config plugins), then regenerate.

## Config

- `app.config.ts` — scheme `expo`, bundle id `your.bundle.identifier`, `experiments: { tsconfigPaths, typedRoutes, reactCompiler }`. Plugins: `expo-router`, `expo-secure-store`, `expo-web-browser`, `expo-splash-screen`.
- `metro.config.ts` — `withVarlockMetroConfig(withUniwindConfig(config, { cssEntryFile: "./src/styles.css" }))`; Metro cache under `node_modules/.cache/metro`.
- Path alias `~/*` → `./src/*` (tsconfig `paths` + `experiments.tsconfigPaths`). `moduleSuffixes` resolves `.ios`/`.android`/`.native`.
- **Native deps are pinned to the SDK 58 set**; CI enforces this with `expo install --check` (the drift gate). Bump them together — `react-native-worklets` is `react-native-reanimated`'s peer:
  - `react-native-reanimated` 4.7.1, `react-native-safe-area-context` ~5.10.1, `react-native-worklets` 0.13.0, `react-native-gesture-handler` ~3.3.0, `react-native-screens` ~4.30.0.
  - Reanimated is linked but **not imported by app code yet**; `SafeAreaView` from `react-native-safe-area-context` is the safe-area path in use (`src/app/index.tsx`).

## Env

- `EXPO_PUBLIC_API_URL` (declared in `.env.schema`, default `http://localhost:3000`) is **inlined into the JS bundle at build time**.
- `getBaseUrl()` (`src/utils/base-url.ts`) prefers the dev client's `hostUri` host (`http://<host>:3000`), falling back to `EXPO_PUBLIC_API_URL` when the dev client is detached.

## Structure

- `index.ts` → `expo-router/entry`; routes live in `src/app/` (`index.tsx`, `_layout.tsx`, `post/[id].tsx`).
- `src/utils/api.tsx` — Eden Treaty `treaty<App>(getBaseUrl(), { credentials: "include" })` that forwards the better-auth cookie on every request; the shared `QueryClient` is exported from here.
- `src/utils/auth.ts` — better-auth client with the `expoClient` plugin (SecureStore, scheme `expo`).
- Clients import **only the type** `import type { App } from "@acme/api"` — a type-only import erased at build time. Never pull server runtime code into the bundle; shared runtime validation goes through `@acme/validators`.

## Testing

Repo rule: **no unit tests** — prefer integration/e2e. Verify with `pnpm typecheck`, `pnpm lint`, `pnpm --filter @acme/expo exec expo export --platform ios`, and a real run (`expo run:ios`) when native code changes.
